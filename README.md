# 无畏契约国服排位表现影响因素分析

基于个人 **73 场国服竞技模式**排位数据的统计分析项目（作品集 1 号）。

- 游戏：《无畏契约》（VALORANT）国服
- 数据区间：2026-07-24 ~ 2026-09-21
- 模式：竞技模式（排位）
- 总成绩：38 胜 35 负，胜率 52.1%

## 为什么用个人数据

国服（WeGame 渠道）没有 Riot 官方开放 API，第三方战绩接口有登录地 IP 校验，
无法从服务器端稳定调用。因此本项目以**本人账号的全量排位对局**为研究总体，
数据通过浏览器控制台在 WeGame 战绩页 DOM 中采集，全程不经过第三方服务器。

## 研究问题

1. 获胜对局与失败对局的 KDA 是否存在显著差异？（两样本 t 检验）
2. 高击杀表现与获胜是否独立？（卡方检验）
3. 是否存在显著的连胜/连败聚集？（游程检验）
4. 击杀、死亡、助攻等表现对……（阶段 4 补充 RR/评分数据后做回归）

> 注：73 场为**全总体而非随机抽样**，结论仅适用于本人该时段的排位表现，
> 不做总体推断，报告中会如实说明这一局限。

## 数据说明

| 文件 | 说明 |
|---|---|
| `data/battles_final.json` | 阶段1-2：73 场基础数据（胜负 / KDA / 日期） |
| `data/battles.csv` | 同上的 CSV 版本 |
| `data/battles_detailed.json` / `.csv` | 阶段3：40 字段宽表，含地图、特工、爆头率、ADR、RR、残局等 |
| `data/raw/` | 浏览器采集的接口原始 JSON（对局 UUID 为不透明 ID，无登录态无法反查） |

字段：

| 字段 | 含义 |
|---|---|
| `date` | 对局日期（页面只有月/日，已按时间顺序推断年份补全） |
| `date_md` | 战绩页原始月/日 |
| `mode` | 模式（均为竞技模式） |
| `win` | 1=胜利，0=失败 |
| `kills` / `deaths` / `assists` | 击杀 / 死亡 / 助攻 |
| `honor` | 荣誉：MVP（胜方最佳）、SVF（疑为败方最佳 SVP，页面原文如此）、空=无 |

数据采集与清洗细节见 `docs/data_collection.md`。
