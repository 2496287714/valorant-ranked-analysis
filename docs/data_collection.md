# 数据采集与清洗记录

## 采集来源

- 页面：WeGame 无畏契约助手战绩页（`wegame.com.cn/helper/valorant/score`）
- 方式：Chrome 开发者工具控制台执行 JS，读取战绩列表 DOM，逐页抓取（每页 10 场）
- 登录态只存在于本人浏览器，采集过程不经过任何第三方服务器

## 为什么不直接调接口

- WeGame `GetBattleList` 接口从非登录地服务器 IP 调用返回 `error_code 8000102`（登录地 IP 校验）
- 在浏览器控制台重放 XHR 时通时不通，常见 `8000114 backend server status failed`
- 因此采用 DOM 抓取作为稳定方案

## DOM 结构要点

- 战绩行：`.newrecord-cell`，classList 含 `win` / `loss`
- 行文本：`竞技模式 25/21/9 09/12 胜利 MVP`（模式、KDA、月/日、胜负、荣誉）
- 分页：`button.vl-pagination-btn.next`，翻页后轮询首行文本变化判断渲染完成

## 踩过的坑

1. **日期列错位**：行文本直接匹配 `\d{1,2}/\d{1,2}` 会先撞上 KDA 里的数字，
   需先剔除 KDA 段再匹配日期。
2. **模式字段污染**：荣誉文本会混入模式列，统一回填为「竞技模式」。
3. **年份缺失**：页面只显示月/日，按对局时间顺序推断年份
   （2026 年 9 月向前，月份回升处跨年补 2025；本批数据最早 2026-07-24，未跨年）。
4. **翻页过快**：Vue 渲染未完成时连续点击会抛 TypeError，翻页后需等待首行内容变化。
5. **荣誉 `SVF`**：共 5 条负场记录荣誉为 `SVF`（疑为常见的败方最佳 SVP，
   以页面原文保留，未做修改）。

## 数据校验

- 总记录数：73（38 胜 / 35 负）
- 无完全重复记录，无同日期 + 同 KDA + 同胜负的重复对局
- KDA 字段均为非负整数，数值范围经人工核验无异常
